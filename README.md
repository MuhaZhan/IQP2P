# IQanat Peer-to-Peer

Ролевая платформа для программы Peer-to-Peer IQanat.

## Роли

| Роль | Возможности |
|------|-------------|
| **Ученик** | Чат своей группы, предметные дуэли, мини-игры, горячая картошка, лидерборд, цвет текста по титулу |
| **Тьютор** | Своя группа, вовлечённость, кинуть «горячую картошку», дуэли тьюторов, Telegram-ссылка |
| **Куратор** | Все группы, полные лидерборды, статистика |

## Быстрый старт

```bash
npm install --legacy-peer-deps
npx prisma db push
npm run db:seed
npm run dev
```

Открой http://localhost:3000

## База данных

Реальная Prisma + SQLite (файл `prisma/dev.db`).  
Для продакшена смени на PostgreSQL в `schema.prisma`.

Аккаунты создаются через seed или напрямую в БД (не публичная регистрация).

## Структура

- Группы по номерам (1, 2, 3…)
- Telegram-ссылка на канал группы (ставит тьютор)
- Поинты → титул → цвет текста в чате
